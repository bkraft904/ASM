# Image manifest

Drop your real photos into this folder using the **exact filenames** below.
The site already references these paths — once a file lands here, refresh
the page and it swaps in automatically (no code changes needed). Until then,
each slot shows a placeholder with the expected filename + recommended size
so you can see exactly what's missing.

| Filename                       | Used for                                   | Recommended size |
|---------------------------------|---------------------------------------------|-------------------|
| `logo.png`                      | Nav + footer wordmark (transparent PNG/SVG) | 600×200 (transparent) |
| `hero-bg.jpg`                   | Full-bleed homepage hero                     | 1920×1080+ |
| `fleet-gt3.jpg`                 | Fleet card — BMW M4 GT3                      | 1400×900 |
| `fleet-touring.jpg`             | Fleet card — Audi RS6 Avant                  | 1400×900 |
| `fleet-hypercar.jpg`            | Fleet card — Hypercar / Le Mans prototype    | 1400×900 |
| `facility-showroom.jpg`         | Facility gallery — two-story showroom        | 1600×1000 |
| `facility-workshop-bays.jpg`    | Facility gallery — 5-bay workshop            | 1600×1000 |
| `facility-lounge.jpg`           | Facility gallery — lounge / hospitality      | 1600×1000 |
| `facility-workshop-detail.jpg`  | Facility gallery — single-bay detail shop    | 1600×1000 |
| `facility-hq-exterior.jpg`      | Facility gallery — HQ exterior               | 1600×1000 |
| `transporter.jpg`               | Operations section — race transporter        | 1920×1080 |

Swap any of these any time; the layout (aspect ratios, crops) is already
locked in via CSS so new photos will drop in cleanly as long as they're
roughly the recommended orientation.
